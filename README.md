# Herramientas para grabaciones

Scripts para Windows que facilitan trabajar con grabaciones de clases y reuniones
(Zoom y otras). No requieren saber programar: se usan con doble clic o con un solo comando.

| Herramienta | Qué hace |
|---|---|
| [**descargar-grabaciones**](descargar-grabaciones/) | Descarga todas las grabaciones en la nube de tu cuenta de Zoom y las ordena por año y mes. |
| [**cortar-video**](cortar-video/) | Divide un video en dos partes en segundos y sin perder calidad. Arrastras el video, escribes el minuto y listo. |

Cada carpeta tiene su propio README con las instrucciones.
